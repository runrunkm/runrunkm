## 👋 About Me / 关于我

I build **autonomous AI agents that operate Unreal Engine like a developer** — they read engine state, write C++ / Blueprint / Lua, run the game, watch what happens, and fix it on their own. I'm the founder and architect of **AGD**, a stealth-stage system exploring how far an agent can carry *real* game development inside UE5.

我构建 **像开发者一样操作虚幻引擎的自主 AI Agent** —— 读取引擎状态、编写 C++ / 蓝图 / Lua、运行游戏、观察结果并自我修复。我是 **AGD** 的创始人与架构师，这是一个仍处隐身阶段的系统，探索 AI Agent 能把虚幻引擎里的*真实*游戏开发推进到多远。
